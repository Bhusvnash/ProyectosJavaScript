# Bootstrap - Recursos y Dependencias Locales

## Descripcion
Carpeta de recursos estaticos que contiene la biblioteca Bootstrap (archivos CSS y JavaScript minificados). Proporciona estilos de diseno responsivo y componentes de interfaz para su utilizacion local e independiente dentro de los proyectos del repositorio sin requerir conexion a internet.

## Funcionalidades
- Sistema de cuadricula responsivo (Grid System) con filas y columnas adaptables a diferentes pantallas.
- Clases de utilidad para espaciado (margenes y rellenos), tipografia, colores, bordes y alineaciones flexibles (Flexbox).
- Componentes visuales predipuestos como tarjetas (cards), botones (buttons), barras de navegacion (navs), tablas (tables) y formularios.
- Componentes interactivos mediante JavaScript como modales (ventanas emergentes), pestanas dinamicas (tabs), alertas y colapsables.
