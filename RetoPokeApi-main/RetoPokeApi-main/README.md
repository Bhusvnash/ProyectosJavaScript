# RetoPokeApi

Una aplicación web interactiva que consume la **PokéAPI** para explorar, buscar y gestionar información sobre Pokémon. Este proyecto fue desarrollado como un reto de programación.

## ✨ Características

- 🔍 **Búsqueda de Pokémon**: Encuentra Pokémon por nombre o ID
- 📊 **Información Detallada**: Visualiza estadísticas, tipos, habilidades y evoluciones
- 💾 **Almacenamiento Local**: Guarda tus Pokémon favoritos
- 📱 **Interfaz Responsiva**: Compatible con dispositivos móviles y desktop
- ⚡ **Carga Rápida**: Caché de datos para mejor rendimiento

## 🛠️ Tecnologías

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **API**: PokéAPI (https://pokeapi.co/)
- **Herramientas**: Git, npm/yarn
- **Navegadores Soportados**: Chrome, Firefox, Safari, Edge (versiones recientes)

## 📦 Requisitos Previos

- Node.js (v14 o superior)
- npm o yarn instalado
- Navegador web moderno
- Conexión a internet
