# Ejercicio 1 - Galeria Interactiva con Eventos de Raton

## Descripcion
Taller practico de manipulacion del DOM donde se genera una galeria dinamica de tres imagenes de animales (gato, perro y loro) y se aplican escuchadores de eventos para sustituir sus imagenes al interactuar con el cursor.

## Funcionalidades
- Creacion dinamica de tarjetas con Bootstrap e insercion en el contenedor principal a partir de un arreglo de datos.
- Intercambio de imagen mediante el evento mouseover:
  - Al colocar el cursor sobre la imagen del gato, cambia por la imagen del loro.
  - Al colocar el cursor sobre la imagen del perro, cambia por una calavera.
  - Al colocar el cursor sobre la imagen del loro, cambia por la imagen del perro.
- Boton de recarga que reinicia la pagina y restaura los estados iniciales de las imagenes.
