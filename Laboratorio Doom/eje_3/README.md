# Ejercicio 3 - Tarjeta de Perfil Profesional (CV)

## Descripcion
Taller practico de construccion programatica de elementos DOM complejos con JavaScript vanilla para generar una tarjeta de presentacion curricular a partir de la informacion contenida en un objeto.

## Funcionalidades
- Disparador de accion mediante boton de presentacion ("Mostrar CV"):
  - Oculta el boton tras ser presionado para evitar duplicar el elemento en la vista.
- Construccion jerarquica de nodos DOM:
  - Estructuracion de tarjeta con fila de Bootstrap, divisiones de columnas para imagen y contenido.
  - Asignacion de fotografia de perfil, nombre completo y descripcion personal.
  - Recorrido iterativo de la lista de lenguajes de programacion dominados para generar insignias estilizadas individuales.
